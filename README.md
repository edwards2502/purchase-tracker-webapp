# purchase-tracker-webapp
# Aplicação Web de Gestão de Vendas

## Visão Geral do Projeto
Aplicação web desenvolvida com Streamlit e Pandas para facilitar o cadastro e o gerenciamento de vendas. O sistema permite armazenar registros, calcular o faturamento e visualizar os resultados de forma organizada.

## Principais Funcionalidades
- Cadastro de vendas.
- Armazenamento de registros.
- Cálculo automático do faturamento.
- Visualização dos resultados.

## Tecnologias Utilizadas
- Python
- Streamlit
- Pandas
